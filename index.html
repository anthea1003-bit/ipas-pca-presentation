01

特徵冗餘／共線性

好幾個欄位量的是同一件事，例如身高 cm 與身高 inch。

CONSEQUENCE模型被重複資訊干擾，迴歸係數也容易不穩定。
PCA RESPONSE把彼此相關的特徵濃縮成一個主成分。
02

高維度詛咒

特徵越多，資料點在高維空間中就變得越稀疏。

CONSEQUENCE距離度量失效，模型需要指數級增加的資料量。
PCA RESPONSE降到少數幾個 PC，讓資料回到較低維空間。
03

雜訊干擾

低變異方向往往只承載量測誤差或隨機擾動。

CONSEQUENCE模型把雜訊當規律學走，導致泛化能力下降。
PCA RESPONSE只保留高變異的 PC，捨棄部分低變異雜訊。

114 年第二梯次・中級科目三 Q35特徵值計算

某公司針對製程感測器資料進行主成分分析（PCA），經標準化與協方差矩陣分解後，得到三個主成分的特徵值如下：

λ₁ = 6.0λ₂ = 3.0λ₃ = 1.0

若團隊決定僅保留能解釋至少 80% 總變異量的主成分，以進行後續模型建構，下列哪一項敘述最合理且數據解讀正確？

總變異量 = 6 + 3 + 1 = 10

  1. 前兩個主成分合計解釋 90% 的總變異量，因此可安全降維至二維，且仍保留大部分資訊
  2. 第一主成分解釋 60% 的變異量，表示資料結構呈現明顯線性關係，僅保留一維即可避免過擬合
  3. 雖然前兩個主成分可解釋超過 80% 變異量，但第二主成分貢獻仍高達 30%，不宜捨棄第三主成分
  4. 三個特徵值相差不大，顯示各主成分變異均衡，降維可能導致資訊損失
答案 APC₁ + PC₂ = (6 + 3) ÷ 10 = 90%，高於至少 80% 的門檻，因此保留前兩個主成分。
114 年第二梯次・中級科目三 Q46PCA 降噪程式題

研究人員使用 PCA 對含雜訊的手寫數字影像降噪，但輸出仍有明顯雜訊。哪一段程式碼需要修改？

  1. 程式碼 A：匯入 PCA
  2. 程式碼 B：pca = PCA()
  3. 程式碼 C：pca.fit(noisy)
  4. 程式碼 D：pca.transform(noisy)
答案 BPCA() 沒有限制主成分數，連雜訊方向也被保留；應改成 PCA(n_components=k)，只留下前 k 個 PC。
115 年第一次・中級科目三 Q6t-SNE vs PCA

某資料科學家欲對 512 維詞嵌入向量（共 10 萬筆）進行視覺化以探索群集結構，同時另一工程師需將 200 個製程特徵降維後作為 XGBoost 的輸入特徵。關於 t-SNE 與 PCA 選型，下列敘述何者最正確？

t-SNE保留局部鄰域，適合探索群集與視覺化
PCA保留全局線性結構，可 transform 新資料
  1. t-SNE 保留全局線性結構，適合作為 XGBoost 的降維前處理
  2. t-SNE 保留局部鄰域結構，適合視覺化；但不保留全局結構，不適合作為模型輸入特徵
  3. PCA 為非線性降維方法，能保留複雜流形結構
  4. t-SNE 與 PCA 皆可直接對新資料進行線性外推
答案 Bt-SNE 偏重局部鄰域且不能直接 transform 新資料；PCA 可線性投影新資料，更適合模型前處理。
115 年第一次・中級科目三 Q7拒絕錯誤使用 PCA

某金融團隊建立信貸風險模型，特徵工程後共產生 200 個變數，其中「月收入」、「年收入」、「季收入」三者高度相關。模型上線後業務單位反映：每次重新訓練後，模型輸出的重要特徵清單在這些高度相關特徵間反覆變動，難以向審查單位解釋。請問下列何者為造成此現象最可能的原因？

認知層次：拒絕錯誤使用｜陷阱：高維＋共線性不等於一律 PCA

  1. 模型使用 L2 正則化，導致所有特徵係數被壓縮至接近零，重要性難以區分
  2. 模型使用 L1 正則化，面對高度相關特徵時隨機保留其中之一，導致每次訓練保留的特徵不穩定
  3. 模型未使用任何正則化，過擬合導致係數每次收斂至不同極值
  4. 特徵數量過多導致梯度消失，應優先進行 PCA 降維再套用正則化
答案 BL1（Lasso）遇到高度相關特徵時，可能不穩定地保留其中之一；D 是 PCA 干擾項，且 PCA 會讓監管解釋更困難。

  2. (B) 需先將類別欄位移除，僅對數值欄位執行 PCA
  3. (C) 需先對所有欄位進行 One-Hot Encoding 後再執行 PCA
  4. (D) PCA 只能處理數值型特徵，需先處理類別欄位（如編碼或排除）後才能執行
答案 D：PCA 只能處理數值；B 太絕對，C 也不是所有稀疏 One-Hot 情境的固定最佳解。

Iris PCA：explained_variance_ratio_🔴 高機率 · 答案 B

根據上述 Iris PCA 程式碼輸出，下列敘述何者正確？

  1. (A) 四個主成分合計解釋約 72.96% 的變異量，資訊損失嚴重
  2. (B) 取前兩個主成分，累積解釋變異量約 95.81%，足以保留大部分資訊
  3. (C) 第三主成分解釋 3.67%，代表該方向完全是雜訊，應直接刪除
  4. (D) explained_variance_ratio_ 的總和不一定等於 1.0
答案 B：0.7296＋0.2285＝0.9581；前兩個 PC 已保留約 95.81%。
Iris PCA：資料洩漏🔴 高機率 · 答案 D

上述 Iris PCA 程式碼存在一個常見的方法論問題，下列敘述何者正確？

  1. (A) 此寫法完全正確，先對全部資料做 PCA 再切 train/test 是標準流程
  2. (B) PCA 是非監督方法，不看 y，所以不可能有資料洩漏
  3. (C) 問題出在 KNN 的 k=5 設定不當，與 PCA 無關
  4. (D) 此寫法存在資料洩漏：StandardScaler 與 PCA 應只對訓練集 fit，再 transform 測試集
答案 D：測試集 X 的統計量也不能偷跑；先切分，再以訓練集 fit，測試集只 transform。

3 句話帶走

①
先找出資料變化最大的方向。

這個方向會成為 PC₁；特徵值和解釋變異量，可以幫我們看看它保留了多少資訊。

②
PCA 會把原始特徵整理成新的主成分。

它屬於非監督、線性的特徵萃取方法，和特徵選擇、LDA、t-SNE 的用途不太一樣。

③
建模前，先把訓練集和測試集分開。

標準化和 PCA 都先用訓練集 fit；放進 Pipeline，流程通常會比較不容易出錯。
